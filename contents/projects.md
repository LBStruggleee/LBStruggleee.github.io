#### KnowFlow

KnowFlow is a traceable RAG knowledge base system for big data course learning. It transforms scattered course materials into a searchable, queryable learning system with source attribution.

- **Tech Stack:** Vue 3, FastAPI, Chroma, DashScope/Qwen, SQLite
- **Features:** Document upload (PDF/DOCX/PPTX/MD/TXT), semantic search, multi-round Q&A with citations, conversation history
- [[Code]](https://github.com/LBStruggleee/KnowFlow)

#### DataQuery-Copilot

A natural language data query automation tool powered by LLM. Users can query data using natural language, and the system automatically generates SQL, executes it, and returns results with visualizations.

- **Tech Stack:** Python, FastAPI, DeepSeek API, React, TypeScript, Vite, SQLite
- **Features:** Natural language to SQL, auto visualization, query caching, SQL auto-retry, batch queries
- [[Code]](https://github.com/LBStruggleee/DataQuery-Copilot)
